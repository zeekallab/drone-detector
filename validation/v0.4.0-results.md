## UVic ISOT captures

Credit: University of Victoria ISOT research group, Z. Chen, I. Traoré,
M. Mamun, and S. Saad. See [fixture provenance](../tests/fixtures/uvic/README.md)
for the official source, citation, member paths and SHA-256 manifest.

`Instruction_injection_8_5_14_4mins.pcap` produces **nine records** with
`protocol=tello-sdk`. Each connection emits at protocol confirmation, then at
least 60 seconds apart. No connection-end duplicate is emitted. Recorded commands
include SDK entry, forward/back movement and clockwise/counterclockwise rotation.
The telemetry identifies drone host 192.168.10.1, with battery percentage, height,
orientation and other reported values. Coordinates are not invented.

The binary replay, manipulation and IP-spoofing fixtures remain **negative**.
They do not match the SDK state grammar, MAVLink CRC framing or legacy DJI framing.
This is a documented binary-Tello coverage gap, not successful attack detection.

The UVic test uses `-C` for offline application-payload inspection independent of
stored transport checksums, and enables Tello ports as MAVLink candidates to check
against cross-protocol false positives. The actual Tello SDK has no application
checksum/authentication to validate.

## Reference and limits

[Ryze Tello SDK 2.0 User Guide](https://dl-cdn.ryzerobotics.com/downloads/Tello/Tello%20SDK%202.0%20User%20Guide.pdf)
provides the state schema, command forms/ranges and port definitions. Explicit
units are retained for height/ToF (cm), attitude (degrees) and battery (%).
Barometer/axis-speed/motor-time fields are labeled raw to avoid assigning uncertain
units/reference frames. Mission-pad local coordinates are not global GPS.

Command correlation is bounded, recent and worker-local. A multiworker sensor may
send different 5-tuples to different workers, preventing command/state correlation;
state detection itself does not need that correlation. Command-only captures,
generic responses, unsupported SDK commands, and binary Tello traffic are not
classified on their own. Identical valid state frames count toward confirmation.
The format can be imitated and is not authenticated. No claims are made about
broad unrelated-traffic false-positive rates or production sensor performance.
