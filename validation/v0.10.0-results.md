# v0.10.0 validation

Validated offline on Zeek 9.0.1 on 2026-11-03. No sensor deployment or live load
test was performed.

**216 synthetic scenarios passed**: the previous 202 plus 14 rapid-replay checks.
New cases cover positive diverse bursts, both age bounds, sub-10-ms duplicates,
insufficient repeats, isolated payload repetition, sparse repetitions, invalid
CRC, response/query exclusion, wrong direction, threshold overrides, cache limits,
independence from a saturated older-replay cache, and no session-end flush.
The full suite also passes the original DJI, kresoin MAVLink and four existing
UVic fixture checks. Synthetic transport checksums are valid; actual Zeek runs
process the tests.

Before this update, all six Replay files were identified as binary Tello but had

The rapid-repeat interval counters may be below the threshold on a particular
alert row because the trigger uses a rolling window and pending findings are
retained until the next eligible emission. Late repeats can remain unreported
when the capture/connection ends before the next allowed row.

## Limits

CRC and exact payload repetition do not prove freshness, authorization or command
acceptance. These one-way Replay captures contain no drone responses. Delayed
capture/mirror duplication can reproduce the pattern, despite the minimum-age
filter. Three normal-flight comparisons are not a universal false-positive
assessment. Different timing, insufficient diversity, altered payloads, absent
originals and connection/worker changes can evade the rule. Bounded state may
omit evidence; `binary_tracking_limited` must be considered. No physical takeover
or command execution verdict is made.
