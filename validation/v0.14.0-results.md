# v0.14.0 validation

Validated offline with Zeek 9.0.1. No sensor deployment or live traffic replay.

- 221 existing synthetic protocol/threshold scenarios pass using explicit legacy
  emission settings, preserving their original assertions.
- New default-policy suite covers first detection, prompt MAVLink/binary/SDK/ARP
  findings, repeat suppression, conditional final flush, video and optional Wi-Fi,
  multi-connection SDK counts, and the renamed field. No unconditional end duplicate.
- Four-process Broker test passes with separate SDK/video workers, refresh,
  expiry, throttling, and bounded receive caches.
- Existing UVic and kresoin real-fixture regressions pass with their legacy
  emission settings. Capture credit: [kresoin](https://github.com/kresoin) and
  [UVic ISOT](https://onlineacademiccommunity.uvic.ca/isot/2024/12/05/drone-datasets/).
- Default-policy real capture results below use local UVic Manipulation/Replay
  captures at original timing and timestamp-compressed 17x timing. Transport
  checksum verification uses `-C` for these supplied captures; protocol CRC
  validation remains enabled. No PCAP binaries are included in this repository.
