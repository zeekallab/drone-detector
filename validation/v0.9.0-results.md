# v0.9.0 validation

Validated offline on Zeek 9.0.1 on 2026-11-03. No live sensor deployment or load
test was performed.

**202 synthetic scenarios passed**: the prior 186 cases plus 16 command-pair
cases. New coverage includes cross-port maneuver history, source-port churn,
fixed-port negatives, missing/stale telemetry, earlier-port reply context,
reply-only negatives, rapid bursts, rolling-window expiry, threshold overrides,
pair/port/UID bounds, query-only churn, incorrect direction and preserving the
pair rate limit when stale command history is refreshed.

The full suite also passes the original DJI, kresoin MAVLink and four existing
UVic fixture regressions. Synthetic packet checksums are valid and Zeek itself
processes the fixtures.

All eight Unauth files trigger both behavioral descriptions and include recognized
response counts. Eight injection files and six MITM station-mode files have no
new churn alerts; the six established injection maneuver detections remain.
All three normal flights have no alerts of any type. The MITM comparisons are
additional SDK command patterns, not verified benign ground truth.

Unauth total log volume falls from 57–223 rows per file in v0.8.0 to 9–33 rows.
Only command summaries use the host-pair rate gate; telemetry/binary/video rows
remain independently emitted, so this is not one global row per drone per minute.
The summary UID/id identifies the triggering event. Related UIDs, commands and
reply counts may describe other connections within the same host pair.

## Reproduction and sources

```sh
DJI_CAPTURE=/path/to/djiuav.pcap.gz python3 tests/run_tests.py
ISOT_CAPTURE_ROOT='/path/to/ISOT Drone Dataset/Raw Data' python3 tests/test_unauth_captures.py
```

Optional fixtures report SKIP when missing. Real-capture replays use `-C` for
payload analysis independent of recorded transport checksums. Existing binary
protocol CRC checks remain enabled; ASCII SDK does not authenticate messages.
[Member hashes](../tests/fixtures/uvic/unauth-manifest.json) identify the eight
reviewed originals. PCAPs are not committed.

## Limits

The alerts describe behavior, not authorization or physical execution. Legitimate
per-command sockets can trigger churn. NAT, spoofing, capture duplication, lost
telemetry and worker distribution affect attribution and coverage. Comparisons
are local to one worker. State/UID bounds can omit evidence; limit flags must be
considered. No session-end flush means late commands/replies can remain unreported.
These samples do not establish a universal false-positive rate or authenticated
request/response correlation.
