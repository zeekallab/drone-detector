# v0.7.0 validation

Validated offline on Zeek 9.0.1, 2026-11-03. No live sensor deployment or load test.

**166 synthetic scenarios passed**: the prior 143 cases and 23 injection-pattern
cases. The full regression suite passed; after tightening response acceptance to
require an observed command on the flow, the SDK and injection-specific tests
and all 17 captures below were rerun successfully. The original DJI, kresoin
MAVLink and existing four UVic fixture checks passed as part of the full suite.

New tests exercise all four axes, sustained opposing commands, one-direction
movement, isolated reversal, queries, `rc`, invalid ranges, minimum counts,
short bursts, span/window requirements, stale telemetry, history bounds,
response categories, sender direction, response-only/telemetry-only negatives
and minute-limited emission without a final flush. Synthetic transport checksums
are valid.

## Reproduction and provenance

```sh
DJI_CAPTURE=/path/to/djiuav.pcap.gz python3 tests/run_tests.py
ISOT_CAPTURE_ROOT='/path/to/ISOT Drone Dataset/Raw Data' python3 tests/test_injection_captures.py
```

The real-capture runner uses `-C` for payload analysis independent of stored
transport checksums. It does not disable Tello binary application CRC validation;
ASCII SDK has no such checksum/authentication. Optional fixtures report SKIP
when absent. [Injection member hashes](../tests/fixtures/uvic/injection-manifest.json)
record the eight reviewed originals; PCAPs are not committed.

## Interpretation limits

This identifies repetitive request behavior, not authorization or physical
execution. Legitimate automated/pilot maneuvers can trigger it. Single malicious
commands and unsupported/encrypted control forms remain gaps. Recent SDK state
and commands must reach the same worker. Comparisons are per connection; sample
bounds and missing packets can omit evidence. No universal false-positive rate
is established by these captures. Alerts use the existing emission interval;
late findings can remain unreported when the flow stops before its next update.
