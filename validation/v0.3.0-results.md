## Interpretation limits

Anomaly thresholds are configurable heuristics, not a trained or benchmarked
attack classifier. Normal commands, multiple ground stations, estimator resets,
or simulation changes can produce similar evidence. Same-identity spoofing,
smooth tampering, unobserved RF links and control-only flows that never meet
protocol confirmation criteria can evade these checks. Log export buffering can
add latency beyond generation time. Pending activity at session end is deliberately
not flushed; lowering the interval trades volume for timeliness.
